Bu projede, Cisco Packet Tracer kullanılarak bir DHCP sunucusu konfigüre edilmiş ve ağdaki cihazlara (PC ve Laptop) otomatik IP adresi dağıtımı sağlanmıştır.

## 🛠️ Kullanılan Teknolojiler & Cihazlar
- **Araç:** Cisco Packet Tracer
- **Cihazlar:** 1x DHCP Server, 1x Switch, 5x PC, 3x Laptop

## 🚀 Öne Çıkan Özellikler
- Dinamik IP Adresi Dağıtımı (DHCP)
- Cihazlar arası ağ iletişimi ve altyapı kurulumu
